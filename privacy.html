プライバシーポリシー

最終更新日: 2026年10月29日

1. 概要

mail-scaner（以下「本アプリ」）は、開発者本人が個人利用のために作成したツールです。 本ポリシーは、本アプリが Google アカウントのデータをどのように扱うかを説明します。

2. アクセスするデータ

本アプリは、Gmail API の読み取り専用権限（gmail.readonly）を使い、受信メールの以下の情報のみを取得します。

  • 送信者（From）
  • 件名（Subject）
  • 受信日時
  • ラベル（カテゴリ・未読・重要マークなど）
  • 配信停止ヘッダー（List-Unsubscribe）の有無

メール本文や添付ファイルは取得しません。

3. データの利用目的

取得したデータは、受信メールの件数・カテゴリ・送信者などを集計した統計レポートを作成し、利用者本人にメールで送信するためだけに使用します。

4. データの保存

取得したデータは集計処理中にのみメモリ上で扱い、データベースやファイルには保存しません。処理が終わると破棄されます。

5. 第三者への提供

取得したデータを第三者に販売・共有・提供することはありません。広告目的での利用もしません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用は、限定的使用（Limited Use）の要件を含む Google API Services User Data Policy に準拠します。

7. アクセス権の取り消し

本アプリへのアクセス権は、Google アカウントの権限ページ からいつでも取り消すことができます。
